# Discord 频道 RSS

接口：`GET /rss/discord/channel/:channelId/:token`。配置了 BasePath 时，在路径前添加该前缀。

例如（占位符，不是真实凭据）：

```text
https://your-yarr.example/rss/discord/channel/1478601254312874024/YOUR_URL_ENCODED_TOKEN
```

`channelId` 为具体频道或帖子 thread 的数字 ID，不是服务器 ID 或分类 ID。`token` 是 Discord 浏览器请求中完整的 Authorization 值，不包含 `Authorization:` 字段名；作为单个 URL 路径段进行百分号编码（例如空格编码为 `%20`）。接口不需要 yarr 登录 Cookie，持有完整 URL 即可读取对应缓存。通过 HTTPS 使用此链接。

## 内容

返回 RSS 2.0，按创建时间倒序取最新 100 条，不限定过去 24 小时。支持文字频道、公告频道、单个 thread、论坛及媒体频道。论坛合并活跃与归档帖子，直接使用列表附带的首帖；缺失首帖时仅保留标题和链接，不逐帖补全、不读取回复、不下载附件、不抓取外链。

文章包含稳定 GUID、标题、原文链接、创建时间、作者、正文、附件及嵌入卡片文字。图片附件内嵌显示并保留原图链接，其他附件显示下载链接；优先按 Discord 返回的图片 MIME 类型识别，缺少类型时按常见图片扩展名识别。每篇文章的首张图片附件还会写入标准 RSS `<enclosure>` 标签，带图片 URL、MIME 类型和 Discord 返回的文件大小（未提供大小时为 0），供文章列表显示封面。没有图片附件时不输出该标签。正文按普通文本转义并保留换行，不解析 Markdown。论坛搜索使用 Discord 网页内部接口，可能随 Discord 更新而变化；需要有频道权限的浏览器 Authorization，Bot 凭据不保证兼容。

## 缓存与首次访问

- 完整成功后随机缓存 2～4 小时，缓存有效期间不会请求 Discord 或验证凭据。
- 缓存过期后立即返回旧内容，并由这次访问触发后台刷新；同一频道和凭据的并发访问共用一个任务。没有定时抓取。
- 首次访问最多等待 25 秒；尚未完成则返回 HTTP 503 和 `Retry-After: 30`，后台继续准备。稍后重试即可，阅读器可能需要手动刷新。yarr 自己的订阅抓取超时更短，首次添加失败时，等待准备完成再添加。
- 单个后台任务最多 3 分钟，包括排队、等待和重试；客户端断开不会取消任务。
- RSS 缓存及故障状态写入 SQLite，跨重启保留。连续 30 天未访问的缓存会在启动或每日清理时删除。
- 每天北京时间 22:00（含）至次日 06:00（不含）不发起 Discord 请求，包括分页和重试。夜间返回上次内容，无缓存则返回 HTTP 503 和中文提示。06:00 后需要再次访问才会抓取。
- 跨入夜间允许已发出的请求结束，但不再请求下一页。不完整结果不会覆盖成功缓存。

所有 HTTP 响应带 `Cache-Control: no-store`，由服务内部缓存 RSS。

## 请求节流与错误

当前 yarr 进程内的所有 Discord 请求串行执行，每次结束后随机间隔 3～7 秒，使用固定浏览器 User-Agent。网络错误或 5xx 最多重试两次，额外退避 5 秒、10 秒。不会发送模拟浏览行为的额外请求；这些措施不保证账号不受限制。

| 情况 | 行为 |
| --- | --- |
| 401 | 返回 HTTP 200 RSS，在旧文章前增加一条凭据失效提示；没有旧文章时只返回提示。停止该 token 的自动重试。 |
| 403 | RSS 提示无访问权限，冷却 15 分钟，不误报为凭据过期。 |
| 404 | RSS 提示频道不存在或不可访问，冷却 15 分钟。 |
| 429 | 结束本次抓取并记录全局限流截止时间，至少冷却 15 分钟；Discord 指定更长时间时按更长时间等待，重启也不绕过。 |
| 网络、5xx、格式异常、任务超时 | 保留旧 RSS 并冷却至少 15 分钟；无旧内容时返回 HTTP 503。 |

同一次鉴权故障使用固定提示文章 GUID，避免重复刷屏。缓存有效期间和夜间不会主动发现 token 失效；后台刷新发现错误后，提示在下一次订阅请求中出现。

替换 token 时，修改订阅链接最后一个路径段，再刷新。缓存按频道 ID 和 token 的 SHA-256 摘要隔离；新 token 不能读取旧 token 的缓存，因此夜间换 token 后需要等到早上。

## 凭据保存边界

新增 Discord 服务不保存原始 token；只在当前请求及其后台任务运行期间临时持有。缓存保存不可逆摘要、RSS 和故障状态，不包含完整接口 URL。新服务错误以及 yarr 的相关订阅错误、图标抓取日志对路径中的 token 脱敏。

**主动将完整 URL 添加为 yarr 订阅时，现有订阅功能仍保存完整订阅链接**，该链接可能出现在 OPML 导出、SQLite 备份及第三方同步结果中。RSS 缓存也随数据库备份保存。这属于订阅功能，不是新增服务的凭据存储。

反向代理访问日志和浏览器历史可能保存完整 URL；部署时对该路径关闭访问日志或脱敏，不要公开分享完整订阅链接。全局限流只协调一个 yarr 进程，多进程实例不共享运行中的请求队列。
