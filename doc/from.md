# 已订阅源 RSS

`GET /rss/from/<订阅链接>` 将 yarr 已保存的订阅源文章输出为 RSS 2.0。例如：

```text
https://your-yarr.example/rss/from/https://linux.do/tag/2234-tag/2234.rss
https://your-yarr.example/rss/from/rsshub://telegram/channel/example
```

配置了 BasePath 时，在 `/rss/from/` 前添加该前缀，例如 `/reader/rss/from/https://linux.do/tag/2234-tag/2234.rss`。

## 链接与访问

- 支持 HTTP(S) 和 `rsshub://` 订阅链接，与 yarr 保存的订阅链接精确匹配。
- 可以直接在路径后拼接完整订阅链接，查询参数属于订阅链接。例如 `/rss/from/https://example.com/feed?a=1&b=2`。
- 保留链接中的转义及查询参数顺序，不合并重定向地址，不转换为其他订阅链接。
- 也可以将整个订阅链接编码为一个 URL 路径片段后拼接；链接包含 `#` 时应使用这种方式。
- 与 Bilibili RSS 接口一样无需 yarr 登录；知道订阅链接的人可以读取对应的本地文章。
- 仅支持 GET，其他方法返回 HTTP 405；无效链接返回 HTTP 400。

## 内容

- 仅查询本地订阅源和文章，不请求原网站、不刷新或自动添加订阅源。
- 未订阅返回 HTTP 404；已订阅但没有文章时返回有效的空 RSS。
- 按文章发布时间倒序返回最多 100 篇，同一时间按本地文章 ID 倒序。不足 100 篇时返回全部现有文章。
- 包含已读、未读和收藏文章，不修改阅读状态。
- 频道使用本地订阅源标题、网站链接和描述；文章保留标题、原文链接、GUID、发布时间、作者、已保存正文和媒体附件。缺少 GUID 时使用稳定的本地文章标识；媒体附件通过 Media RSS 扩展保留链接、类别和描述。

## 缓存

- 成功响应使用进程内存缓存，有效期为 5 分钟，避免重复查询文章。
- 缓存不跨服务重启保留；重启后首次访问重新生成响应。
- 缓存期间新增文章、修改订阅源和删除订阅源最多延迟 5 分钟生效，过期后的首次访问重新查询并生成响应。
- 未订阅和错误响应不缓存，同一订阅链接的并发请求共用生成结果。
- HTTP 响应使用 `Cache-Control: no-store`，由服务内部管理缓存。
